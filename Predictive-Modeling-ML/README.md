# Predictive Modeling Using Machine Learning

## Objective
Build a machine learning model to predict student pass/fail outcomes.

## Algorithms Used
- Random Forest Classifier
- Train Test Split
- Label Encoding

## Features
- Data preprocessing
- Missing value handling
- Model training
- Accuracy evaluation
- Confusion Matrix
- ROC Curve

## Run Project

```bash
pip install -r requirements.txt
python main.py
```
